# E-Commerce Management System

## Overview

A Full-Stack E-Commerce Management System built using React.js, Spring Boot, Spring Data JPA, Hibernate, and PostgreSQL.
The application enables users to manage products, browse available items, add products to the cart, and perform product-related operations 
through a responsive user interface and RESTful backend services.

## Features

- Product Management (Add, Update, Delete, View Products)
- Shopping Cart Functionality
- RESTful API Development
- React.js Frontend Integration
- Context API for State Management
- Axios for API Communication
- PostgreSQL Database Integration
- Responsive User Interface
- Layered Architecture (Controller-Service-Repository)
- CRUD Operations
